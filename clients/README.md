# Turing Tarpit — Mobile Client (Expo)

React Native + Expo client for the Turing Tarpit Developer OS.

## Stack
- Expo SDK 52 + Expo Router (file-based)
- TypeScript, TanStack Query, Zustand
- REST + Connect/gRPC-Web for Auth & Messaging
- SecureStore for PASETO sessions

## Quick start
```bash
cp .env.example .env
npm install
npx expo start
```
