# Product vision

**Turing Tarpit** is a proprietary, self-hosted **AI-native Developer OS**.

Humans and agents (Pearl) share channels, git, issues, compute, and audit. Secrets never become chat paste or model context. Compute runs on metal you rent; KEK stays in-house.

## Pillars

1. **One lifecycle** — code → conversation → review → deploy → observe  
2. **Transparency** — activity blend over vanity heatmaps  
3. **Agent-native** — same permissions and trails; dangerous actions gated  
4. **Self-hosted sovereignty** — Postgres + Redis + your object store + `tt-kms` on your bare metal  
5. **Backend-first** — solid control plane; UI is a separate CMP app  

## Name

Ironic: not a tarpit. The product is meant to *complete* the loop, not trap you in protocol tax (Nostr/fed “everywhere” refactors).
